# Deployment

Deploy the Next.js application to a Node-compatible platform and Supabase to its managed service or an equivalent supported environment. Configure all variables from `.env.example`, apply migrations before directing traffic, set exact authentication redirect URLs, and run the verification commands. Rotate bootstrap secrets after owner setup and keep service credentials only in encrypted server-side settings. Enable database backups, point-in-time recovery, log retention, and alerting before production traffic.
